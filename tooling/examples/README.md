# Examples Showcase

These examples are intentionally small and executable as prompts. They
demonstrate common capabilities and complete quirk flows without requiring
external services.

| Example | Demonstrates |
| --- | --- |
| `simple-validation.md` | structure and anti-pattern validation |
| `bug-fixing.md` | diagnosis, implementation, and review |
| `feature-development.md` | specification through publication |
| `refactoring.md` | dependency-aware safe change |

Try the lab commands from [the Skill Lab guide](../../docs/agents/skill-lab.md)
against any example's referenced Skill.
