# AGENTS.md

Instructions for coding agents working in this repository. This file complements `README.md` (for humans) with the operational rules an agent needs.

## Repository shape

- Canonical skills live in `.agents/skills/` as `<domain>/<skill>/SKILL.md` directories. They are the only source of truth for skill content.
- `.claude/skills/` is a generated compatibility view of relative symlinks. It is committed intentionally so Claude-style consumers can discover the same canonical skills, but it is regenerated by bundle tooling; never create, edit, or delete entries there by hand.
- `skills-lock.json` records per-skill SHA-256 hashes. Editing a `SKILL.md` requires re-locking the corresponding hash, or the semantic audit fails.
- Project vocabulary is authoritative in [CONTEXT.md](CONTEXT.md): quirk Skills, quirk Method, canonical skill, compatibility view, provenance. Use these terms; do not import vocabulary from unrelated repositories.
- `.agents/AGENTS.md` covers the bundle directory itself; this file covers the repository.

## Work-item governance

- Work-item governance lives in `docs/reference/agents/`. Read `docs/reference/agents/index.md` first before routing specs, tickets, project boards, or publication flows; `work-item-router` enforces the same preflight.
- Preserve the canonical work-item metadata shape from `docs/reference/agents/work-item-format.md` whenever specs, tickets, or PR bodies are produced.
- Triage labels and tracker configuration follow `docs/reference/agents/triage-labels.md` and `docs/reference/agents/issue-tracker.md`.

## Method

- The bundle's own quirk Method applies to work done in this repo: artifact-first design, state-machine workflows, and shift-left quality gates.
- Keep changes inside the declared scope of the task, skill, or ticket you are executing. Surface blockers instead of broadening scope.
- Reference issues and tickets by name, not by bare ids.
- Never merge with unresolved review findings. Findings from `review-pr` separate into Standards and Spec axes; repair them with an explicit plan via `plan-review-fixes` and `implement-review-fixes`, then re-review.

## Commands

- Full local gate (run before claiming any work done): `node .agents/skills/platform/check-all.mjs`
- Tests: `node --test tests/*.test.mjs`
- Regenerate projections (CATALOG.md, llms.txt, `.claude-plugin/marketplace.json`, and committed generated compatibility views): `node scripts/sync-registry.mjs --write`
- Version alignment is enforced by `tests/version-consistency.test.mjs` (VERSION, package.json, registry.yaml, README badge).

## Style

- Canonical skills, prompts, and this file are written in English.
- Keep generated artifacts in sync with `.agents/skills/`; never hand-edit them.
- Do not commit unless explicitly asked.
