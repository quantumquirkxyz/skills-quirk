# PR Body

Use a short body with:

- Summary
- Why
- Impact
- Validation
- Review Focus
- Development
- Linked Issue (number, verified identity)
- Metadata Copy Policy (assignees, reviewer policy, labels/state/triage, milestone, projects/item IDs, Project V2 fields, relationships, development linkage)
- Unsupported or Partial Metadata (recorded outcome and reason)
