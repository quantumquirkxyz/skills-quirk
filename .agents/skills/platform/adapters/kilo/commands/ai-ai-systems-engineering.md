# ai-systems-engineering

When to use: Engineer complete AI systems by integrating product requirements, models, data, evaluation, safety, security, serving, fallback, human oversight, monitoring, cost, and latency; use when an AI feature needs an end-to-end production contract rather than isolated MLOps or prompt work.

## Workflow

1. Frame the system
2. Define contracts and data boundaries
3. Build the evaluation matrix
4. Model abuse and safety
5. Specify serving and fallbacks
6. Assign human oversight
7. Define monitoring and change gates

## Deliverables

- ai-system artifact

## Guardrails

- risk: high; trust tier: 4; approval required: yes
- side effects: none
- isolation: none; model tier: reasoning

Stop when: All required artifact sections are complete, risks and unknowns are explicit, approval gates are identified, and JSON/schema plus Markdown/diff checks pass.
