## Approaches tried

- 2026-10-08: ran `npm run validate|test|audit|security|score` directly as the first audit step. Cheap and high-signal — it exposed the 242-vs-254 gap immediately. Reusable: run the bundle gates first, then distrust their `pass` verdicts and audit the gate code itself.
- 2026-10-08: dispatched 4 parallel read-only `explore` subagents split by concern (pipeline integrity / parity+docs+hygiene / platform tooling / tests+CI+packaging). High yield: every finding carried a `file:line`, and two of my own pre-audit conclusions were falsified by them. Lesson: verify an assumed root cause against the source walk before recording it as a durable learning.
